# LYStackRouter 0.2.0 计划

目标是面向组件化、模块化 UIKit 应用的通用开源路由库，全部公开材料使用通用示例。

- [x] 审查与缺陷复现：
  - 动画复用；
  - 兜底等待域；
  - 来源及清理语义。
- [x] 打开接口：
  - `LYOpenOptions`；
  - 静态 `canOpen` / `canOpenURL`；
  - 完整选项透传。
- [x] 模态执行域：
  - 绑定目标栈与代理事件；
  - 关闭与返回抢占；
  - 迟到回调拦截。
- [x] 可注入客户端：
  - 弱来源；
  - 会话代次保护；
  - `open` / `openURL` / `dismiss`；
  - 测试替身。
- [x] 工具与示例：
  - `LYWindowContext`；
  - 四个独立包与独立 Demo；
  - 嵌套导航与会话恢复。
- [x] 第二轮审查修复：
  - 登录后客户端；
  - 无活跃栈请求；
  - 来源结果表；
  - 丢弃回调；
  - 模态清理语义；
  - 代理转发。
- [x] 发布：GitHub Actions 三个 job 通过后合入 `main` 并打 tag `0.2.0`。
